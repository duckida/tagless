# wordle clone
![Hackatime Badge](https://hackatime-badge.hackclub.com/U0AF7QR9J77/tagless?style=flat)

A Wordle clone using no HTML tags other than `<html>`, `<head>`, `<body>`, `<meta>`, `<script>`, `<style>`, and `<canvas>`!

It uses the canvas API and key events to render text! The page appears blank on load, but type a letter and it'll show up! Click enter after 5 letters to submit your word. 

Yellow means the letter is in the word but in the wrong place. Green means the letter is in the word & in the right place! Gray means the letter is not in the word.

Currently only works on devices which have a keyboard.
